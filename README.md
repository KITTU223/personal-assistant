## Telegram AI bot

`POST /telegram/webhook` answers text messages with a reply generated by OpenAI `gpt-6-luna` through the AI SDK. Each message is answered on its own, with no conversation history.

Set `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` and `OPENAI_API_KEY` in `.env`. The secret must be 1-256 characters from `A-Z`, `a-z`, `0-9`, `_` and `-`.

Telegram only delivers to public HTTPS URLs on ports 443, 80, 88 or 8443. Once the app is reachable, register the webhook:

```
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook" \
  -d "url=https://your-domain.example/telegram/webhook" \
  -d "secret_token=$TELEGRAM_WEBHOOK_SECRET" \
  -d 'allowed_updates=["message"]'
```

Check delivery errors with `getWebhookInfo`:

```
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getWebhookInfo"
```

## Deploy to Cloudflare Workers

`npm run deploy` builds the Worker from `src/app.ts` and uploads the secrets listed in `worker.secrets.env`, taking their values from `.env`. `npm run dev:worker` runs it locally in the Workers runtime.
